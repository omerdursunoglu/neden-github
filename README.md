# Neden GitHub Kullanmalıyız? 🐙

Kuzenime ve yazılıma yeni başlayanlara GitHub'ın önemini anlatmak için hazırlanmış basit ve eğlenceli web sayfası.

## 🚀 İçerik
- ⏳ **Versiyon Kontrolü:** Kod geçmişi ve zaman makinesi mantığı.
- ☁️ **Bulut Yedekleme:** Kodların güvende kalması.
- 🤝 **Takım Çalışması:** Çakışma olmadan eş zamanlı geliştirme.
- 💼 **Yazılımcı Portfolyosu:** Projeleri sergileme ve CV oluşturma.
- 🌍 **Açık Kaynak:** Dünyanın dört bir yanındaki projeleri inceleme ve katkıda bulunma.

## 💻 Nasıl Çalıştırılır?
`index.html` dosyasını herhangi bir web tarayıcısında (Chrome, Safari, Edge vb.) açmanız yeterlidir.
