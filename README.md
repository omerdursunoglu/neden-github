# Neden GitHub Kullanmalıyız? 🐙

Kuzenime ve yazılıma yeni başlayanlara GitHub'ın önemini anlatmak için hazırlanmış interaktif ve eğlenceli web sayfası.

## 🚀 İçerik
- ⏳ **Versiyon Kontrolü:** Kod geçmişi ve zaman makinesi mantığı.
- ☁️ **Bulut Yedekleme:** Kodların güvende kalması.
- 🤝 **Takım Çalışması:** Çakışma olmadan eş zamanlı geliştirme.
- 💼 **Yazılımcı Portfolyosu:** Projeleri sergileme ve CV oluşturma.
- 🌍 **Açık Kaynak:** Dünyanın dört bir yanındaki projeleri inceleme ve katkıda bulunma.

---

## 📋 Sürüm Notları (Changelog)

### [v2.0.0] - İnteraktif Simülatör ve Git Sözlüğü
Bu sürümde kuzenimizin konuları daha rahat pekiştirebilmesi için sayfa interaktif hale getirildi:
- 🎮 **İnteraktif Senaryo Simülatörü:** Bilgisayar çökmesi, kodun bozulması veya takım çalışması senaryolarına tıklayarak GitHub'ın nasıl çözüm sunduğunu gösteren bölüm eklendi.
- 📖 **Hızlı Git Sözlüğü:** `Commit`, `Push`, `Pull`, `Branch`, `Pull Request` ve `Repo` gibi temel kavramların 1 cümlelik sade açıklamaları eklendi.
- 🎨 **Tasarım Güncellemeleri:** Sürüm etiketi (badge), yeni ızgara (grid) yerleşimi ve GitHub reposuna doğrudan yönlendiren buton eklendi.

### [v1.0.0] - İlk Sürüm
- 5 temel GitHub süper gücünü açıklayan ilk HTML sayfası ve temel stil tasarımı.
